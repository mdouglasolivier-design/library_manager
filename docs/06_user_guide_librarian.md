# Librarian User Guide

# Ebook Reservations

Readers can submit a reservation request from **Library → Ebook Reservations**.
Each reader may have one pending request per ebook. Readers can see only their
own requests and cannot change their status.

Librarians can review all requests from the same menu. Open a pending
reservation and choose **Mark Fulfilled** when it has been processed, or
**Cancel Reservation** to close it without fulfillment. A reader may submit a
new request after a reservation is cancelled.

# Member Email Notifications

When a member submits a borrowing request or reservation, or a librarian
approves/rejects a request or fulfills a reservation, the portal notification
is also queued by email when the member's contact has an email address.
Notifications remain visible in **My Library → Notifications** if no address
is available.

# eBook Overdue Reminders

An automatic daily job queues one reminder per overdue active eBook loan each
day until the loan is returned. The last reminder date is shown on the loan
record. Confirm that the borrower contact has a current email address and that
outgoing mail is configured in Odoo. The reminder scheduler can be reviewed
under **Settings → Technical → Automation → Scheduled Actions**.
