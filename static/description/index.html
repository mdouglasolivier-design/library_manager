Library Manager

Books, lending, loan history and printable reports, all in one simple Odoo app.

Everything a small library needs

Set up in minutes, no accounting knowledge required.

Book catalogue

Title, author, unique ISBN, category, pages and description. Archive books instead of deleting them.

Lending and returns

Lend a book to any contact with one click. A 14-day due date is set automatically.

Full loan history

Every borrow and return is recorded, with return date and days late. See it on each book.

Overdue tracking

Overdue loans are highlighted in red and can be filtered, grouped and searched instantly.

PDF reports

Loan receipts with barcode, overdue lists and credit-card sized member cards.

Filters and Excel export

Ready-made saved filters and export templates for loans and the book catalogue.

How it works

1

Add your books

Create a book record or import your whole catalogue from a spreadsheet.

2

Lend and return

Choose the borrower, press Lend Book, and press Return Book when it comes back.

3

Track and report

Follow overdue books, print receipts and member cards, and export to Excel.

Included reports

Report Where to find it What it shows
Loan Receipt Loans, then Print Borrower, book, dates, barcode and signature lines
Overdue Loans List Library, then Reports Late loans as of any date, with phone numbers and days late
